ScreenGo 是一款现代、强大且易于使用的 Chrome 屏幕录制扩展。无论您是需要录制教程、游戏精彩瞬间、在线会议还是软件 Bug 报告，ScreenGo 都能通过其多样的录制模式和高性能的区域选择工具满足您的需求。

✨ 核心功能：

🎥 多模式录制
支持录制整个屏幕、特定的应用程序窗口或单个 Chrome 标签页。

📐 高性能区域裁剪
实现零延迟区域裁剪。只需拖拽即可精确选择您想要录制的屏幕区域。

🎵 全面音频支持
支持同时录制系统内部音频和麦克风声音。非常适合制作带解说的教程或录制在线会议。

💾 高质量导出
录制视频默认导出为高质量的 WebM 格式 (VP8/VP9)，方便分享或后期编辑。

🎨 现代化 UI 设计
简洁美观的响应式控制面板，支持随意拖拽移动，确保录制时不会遮挡您的视线。

🌍 隐私优先
所有录制过程均在您的本地计算机上完成，视频文件直接保存到本地，绝不上传至云端。

使用方法：
1. 点击浏览器工具栏中的 ScreenGo 图标。
2. 选择录制页面(可框选区域)、窗口或全屏。
3. 根据需要开启系统音频或麦克风。
4. 点击“开始录制”。
