ScreenGo 是一款現代、強大且易於使用的 Chrome 螢幕錄製擴充功能。無論您是需要錄製教學、遊戲精彩瞬間、線上會議還是軟體 Bug 報告，ScreenGo 都能透過其多樣的錄製模式和高效能的區域選擇工具滿足您的需求。

✨ 核心功能：

🎥 多模式錄製
支援錄製整個螢幕、特定的應用程式視窗或單個 Chrome 分頁。

📐 高效能區域裁剪
實現零延遲區域裁剪。只需拖曳即可精確選擇您想要錄製的螢幕區域。

🎵 全面音訊支援
支援同時錄製系統內部音訊和麥克風聲音。非常適合製作帶解說的教學或錄製線上會議。

✂️ 影片剪輯與預覽
錄製完成後立即預覽影片，並提供簡單易用的裁剪工具，只保留精彩片段。

💾 多格式匯出
支援匯出為 WebM 或通用的 MP4 格式，方便分享到任何平台。

🎨 現代化 UI 設計
簡潔美觀的響應式控制面板，支援隨意拖曳移動，確保錄製時不會遮擋您的視線。

🌍 隱私優先
所有錄製過程均在您的本機電腦上完成，影片檔案直接儲存到本機，絕不截取您的資料。

使用方法：
1. 點擊瀏覽器工具列中的 ScreenGo 圖示。
2. 選擇錄製頁面(可框選區域)、視窗或全螢幕。
3. 根據需要開啟系統音訊或麥克風。
4. 點擊「開始錄製」。
5. 錄製結束後，在預覽頁面檢查影片，可選擇裁剪並匯出為 WebM 或 MP4。
